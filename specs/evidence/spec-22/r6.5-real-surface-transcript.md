## What Remains Is NOT Noise

Every remaining undefined-class violation falls into categories that **cannot be resolved through static analysis of a CSS file**:

1. **Tailwind JIT CSS variable classes** — Shadcn/ui defines theme colors as CSS custom properties in `@layer base { :root { --primary: ... } }`. Tailwind's JIT compiler generates utility classes (`bg-primary`, `text-muted-foreground`) at build time by scanning `tailwind.config.ts` for the `colors` theme extension. A static analyzer has no visibility into this build-step generation without executing the Tailwind compiler or parsing the config's theme section.

2. **Fractional spacing** — `h-3.5`, `w-3.5` come from project-specific `spacing` config in `tailwind.config.ts`. No dictionary can anticipate arbitrary spacing scales.

3. **Custom component classes** — `board-row`, `keyboard-row` are defined in project CSS modules or `@layer components`. They are not Tailwind utility classes.

4. **Opacity modifiers on CSS variable classes** — `bg-primary/20` is a CSS variable class + Tailwind opacity modifier. The base class itself is JIT-generated (category 1); the opacity suffix is mechanically handleable but moot when the base isn't detectable.

5. **Arbitrary variant combinations** — `supports-[backdrop-filter]:bg-card/80` combines an arbitrary variant with a CSS variable class + opacity.

6. **Vendor-prefixed non-standard properties** — `-webkit-overflow-scrolling-touch` is not a Tailwind class; it appears in source as a raw CSS property.

### Path Forward for Remaining Categories

| Fix | Scope | Effort |
|-----|-------|--------|
| `tailwind.config.ts` theme parsing | Shadcn/ui CSS variable classes | ~2 days — parse theme.extends.colors, map to utility prefixes |
| `tailwind.config.ts` spacing scale | Fractional spacing | ~1 day — parse theme.extends.spacing |
| User-configured class allowlist | Custom component classes | ~0.5 day — config field in `.codeauditor.json` |
| Opacity splitting pre-resolution | CSS var + opacity combos | Depends on CSS var fix landing first |

**None of these are "dictionary gaps" or "noise."** They are legitimate detection gaps requiring build-level or config-level knowledge beyond a static CSS file scan.
