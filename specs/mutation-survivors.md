summary of it is not the finding.

`coverageAnalysis: 'perTest'`, `inPlace: true`, `ignoreStatic: true`, scoped to

## 4. Real gaps found and fixed

Triage of the **1,682 logic survivors** surfaced one self-contained, high-leverage
correctness surface — the cross-language dependency-graph core
(`src/analyzers/cross-language/DependencyGraphBuilder.ts`) — where six guards had
a distinguishing case that no existing test exercised. Each was fixed by adding a
test (never by deleting a mutant or narrowing scope). Source unchanged; only
`DependencyGraphBuilder.spec.ts` grew.

| # | survivor (guard mutated) | why it survived | test added (asserts) | kill verified |
| --- | --- | --- | --- | ---: |
| 1 | `nodeIds.has(sourceId) && nodeIds.has(targetId)` → `\|\|` (edge filter) | no test passed a reference whose endpoint is not a node | a ref to `ghost`/`phantom` is dropped, `edges = ['a->b']` | ✅ |
| 2 | `while (w !== v)` → `w === v` (Tarjan SCC pop) | existing SCC tests used cycles at the DFS root, where over/under-popping leaves the *count* unchanged | a singleton child beside a 2-cycle counts as 2 SCCs (mutant: 3) | ✅ |
| 3 | `if (nodeIds.length < 3) continue` → `<= 3` / `>= 3` (cluster min size) | `tight-coupling` had **no test at all** | 3-node cohesive cluster fires; 2-node cluster does not | ✅ |
| 4 | `pathIndex.get(neighbor) ?? 0` → `&& 0` (cycle-start lookup) | cycles were only ever at the DFS root (start index 0) | a `b ⇄ c` cycle under `a` reports `beta → gamma`, not `alpha → beta → gamma` | ✅ |
| 5 | `metadata?.isExported === true` → `false` (orphan export guard) | orphan tests used `visibility: 'public'`, never `isExported` | a `metadata.isExported` private entity is not orphaned | ✅ |
| 6 | `isTestFile(...)` OR-chain (`includes('test')`, `endsWith('.test.ts')`, …) | no test used an actual test-file path | `foo.test.ts` is excluded by default, included when opted in | ✅ |

Kills were verified by applying each mutation to the source by hand and running
the suite (1 failing test per mutation), then restoring. Source is left
un-mutated (checked: no `stryMutAct_`/`stryCov_` markers).

The graph code itself was **correct** in all six cases — these are coverage gaps,
not bugs. That is the expected R1 outcome for code this recent: the invariants
hold; the suite did not pin the boundaries that prove they hold.

## 6. Grounds rubric (how a survivor is classified)

- **Uninteresting** — the mutant changes a value no consumer observes: a message
  string, a log line, a formatting ternary, a regex that matches the same corpus,
  a literal table entry, a removed statement in a dead branch. Evidence: the
  mutator is one of StringLiteral / ConditionalExpression / BlockStatement /
  Regex / ArrayDeclaration / ObjectLiteral / MethodExpression / ArrowFunction.
- **Coverage gap (NoCoverage)** — no test executed the mutant. Not a defect.
- **Real gap** — a logic mutator (Equality/Logical/Arithmetic/Boolean/
  OptionalChaining/Update/Unary/Assignment) that survived *with* coverage: a
  correctness guard with an unpinned boundary. Fix with a test (§4).
