## Notes

**Go — message-overclaims-computation (third state; fixable by rewording).** A state distinct from crude/dishonest: the predicate is defensible, but the emitted message asserts something the predicate never checked. Fix is a wording change, not a reimplementation. Carry this forward across analyzers. Go rows affected:

- `channels/concurrency` — computes "signature contains `chan` and complexity > 3"; message says "review for potential deadlocks" (deadlock never computed).
- `solid/open-closed` (switch and type-switch) — computes "> 5 cases"; message says "consider using polymorphism / interfaces" (assumes the switch is extensible-type dispatch, not a stable enum).
- `imports/import-organization` — computes "> 10 imports"; message says "reducing dependencies" (import count ≠ dependency count).

**Go — extraction-layer placeholder.** `parser.go:355` `typeToString` returns the literal `"func"` for `*ast.FuncType` ("Simplified for now"). This feeds `ReturnType`, `Signature`, and field `Type` — the inputs of the crude/dishonest rules — but NOT the one honest rule (`imports/import-style`, which reads `importSpec.Name` directly from go/ast). The honest rule's data is clean; the placeholder compounds the proxy nature of the rules that read collapsed type strings.

## Notes — solid

**solid — message-overclaims-computation (fixable by rewording).** Unlike Go, none of the TS SOLID rules are name/doc-comment proxies (no dishonest rows); the recurring defect is a defensible predicate paired with a message that asserts more than was checked:

- `solid/open-closed` — computes "has `instanceof` against a user-defined type"; message says "appears to be frequently modified" (modification frequency never computed). Registry message (`violates the Open/Closed Principle`) also diverges from the emitted message.
- `solid/liskov-substitution` — computes "contains a `throw_statement`"; message says "Ensure this doesn't violate parent class contract" (parent never inspected).
- `solid/class-size` — computes method count + aggregate McCC; message says "split responsibilities" (size ≠ responsibility).
- `solid/dependency-inversion` — computes "instantiates a non-builtin/non-self PascalCase type"; message says "concrete *dependency*" (a value object/DTO is not a dependency).

**solid — placeholder comment.** `UniversalSOLIDAnalyzer.ts:445-446` — "Check if class overrides parent methods with incompatible signatures / This would require more sophisticated type analysis / For now, we'll check basic patterns" (the LSP check). This is the one live placeholder; the `maxClassComplexity` heuristic is DEPRECATED, not live (`:14-22`).

**solid — no near-miss test.** Only `solid/dependency-inversion` has an execution-level near-miss suite (`UniversalSOLIDAnalyzer.spec.ts` — 7 tests, all DIP: builtins/self/lowercase, member-access, constructor-injection, unresolved bare type). The other six rules declare registry near-miss samples but are never executed against the real analyzer.
