## Notes

**Go — message-overclaims-computation (third state; fixable by rewording).** A state distinct from crude/dishonest: the predicate is defensible, but the emitted message asserts something the predicate never checked. Fix is a wording change, not a reimplementation. Carry this forward across analyzers. Go rows affected:
